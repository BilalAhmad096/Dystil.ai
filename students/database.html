Instagram and TikTok open links inside their own browsers, which usually send no referrer, so those visits land under Direct. Put ?ref=instagram on the link in your bio and it will be counted properly. Registrations are counted from what each person's browser recorded when they first arrived, so that column is the reliable one.

Cloudflare sampled this window, so these figures are estimates and will look rounded. A shorter window is measured directly and is the more accurate one.

Test an email

Sends one copy to one person on the team. Tests are never recorded, so the same email can be checked as often as you like and nobody on the real list loses their place.

Reminders

Each message goes to everyone who has registered, once. Both names write to the same record, so sending “2 days to go” from Frank means the Dystil button skips those people rather than mailing them again. Sends go one at a time, so allow around twelve minutes.
